# Lanilot — план реализации

## Готово в локальном MVP

- [x] Поиск грузов и компактная выдача.
- [x] Карточка с маршрутом и расчётом маржи.
- [x] Предложения и демо-переписка с брокером.
- [x] Создание, редактирование, отмена и восстановление рейса.
- [x] Планировщик, проверки ресурсов и история отмен/восстановлений.
- [x] Настройки профиля перевозчика и расходов по умолчанию.
- [x] Автоматический добавочный seed без сброса пользовательских изменений.

## Следующие локальные этапы

- [x] Автопарк и водители: создание/редактирование записей, доступность, тип техники.
- [x] Radar: сохранённые критерии и просмотр подходящих демо-грузов.
- [x] Документы рейса: rate confirmation, BOL, POD, отметки получения.
- [x] Финансы: ручной учёт доходов/расходов, прибыль, счета, оплата и задолженность.
- [x] Вложения в чат: документы, изображения, аудио/видео и просмотр на тёмном фоне.

- [x] Раздел централизованных интеграций: серверные настройки, статусы и проверка соединения, демо-seed.

- [x] Бот компании в Telegram: шифрование токена, проверки, тест, настройки отбора, ИИ-коннектор и журнал уведомлений.

- [x] Фронтенд ИИ-помощника: история запросов, демо-подбор, расчётная прибыль и переход в груз.

## Для перехода к подключённому продукту

- [ ] Авторизация, организации, команда и права доступа.
- [ ] Подключения почты и площадок с учётными данными пользователя.
- [ ] Фоновые задания, мониторинг источников и реальная доставка уведомлений.
- [ ] AI-помощник поверх доступных инструментов и подтверждений пользователя.
